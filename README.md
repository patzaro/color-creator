# Color Creator – 4 Versions

This repository contains 4 different implementations of a simple RGB color creator web application. Each version was generated by a different Large Language Model (LLM) as part of a comparative analysis of their code generation capabilities for simple web applications.

## Purpose

The goal of this project was to evaluate and compare how different LLMs approach the same straightforward task: creating a single-file HTML page with:

- Three sliders for RGB values (0-255)
- Real-time color preview in a circular element
- Display of the resulting color in both RGB and hexadecimal formats
- No external dependencies or API keys

## The Models Tested

| Version | LLM |
|---------|-----|
| v1 | DeepSeek v4|
| v2 | Qwen 3.8 Max|
| v3 | Claude Sonnet 5|
| v4 | ChatGPT 5.6 Luna|

## How to Use

1. Navigate to any version folder
2. Open `index.html` in your browser
3. Adjust the R, G, B sliders
